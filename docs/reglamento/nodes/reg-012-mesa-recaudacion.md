# Mesa de Recaudación y Búsqueda de Fondos

## Idea atómica

La Mesa de Recaudación es el **brazo financiero** del Área de Dirección, encargada de buscar ingresos lícitos para el Proyecto Migala, tanto en especie como económicos, y canalizarlos al área financiera.

## Tipos de recursos (Art. 39)

| Tipo | Ejemplos | Flujo |
|:----:|----------|-------|
| **Económico** | Papel moneda, cheque, transferencia | → Tesorería → Contabilidad |
| **En especie** | Bienes valuados a precio de mercado | → Informe a Contabilidad → Resguardo → Distribución |

## Proceso de recaudación

```
Mesa identifica oportunidad
  → Obtiene recurso (económico o en especie)
    → Documenta procedencia y finalidad
      → Entrega a Contabilidad (Tesorería)
        → Contabilidad documenta fiscalmente
          → Área de Transparencia publica
```

## Funciones específicas (Arts. 40-42)

- Identificar **convocatorias** municipales, estatales, nacionales e internacionales
- Competir por recursos económicos para proyectos
- **Asesorar** a comisiones estatales, temáticas y transversales sobre convocatorias
- Hacer llegar **links de convocatorias** a los grupos interesados
- Ser **apoyo administrativo** para los grupos que quieran participar

## Perfil de integrantes

Miembros con **conocimiento del proceso** para participar en convocatorias de financiamiento.

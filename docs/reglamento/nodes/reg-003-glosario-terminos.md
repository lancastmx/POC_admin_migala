# Glosario de Términos del Reglamento

## Idea atómica

Conjunto de definiciones formales que estandarizan el lenguaje dentro del Proyecto Migala. Cada término tiene una acepción específica y vinculante para la interpretación del reglamento.

## Definiciones (Art. 3)

| # | Término | Definición |
|:-:|---------|------------|
| I | **Acciones Afirmativas** | Acciones para compensar condiciones de grupos históricamente relegados: Diversidad Sexual, Pueblos Originarios, Discapacitados, Migrantes, Afromexicanas |
| II | **Órganos** | Cualquier área, coordinación, comité o grupo que integre la estructura organizacional |
| III | **Miembros** | Conjunto de afiliados y simpatizantes |
| IV | **Áreas** | Estructuras organizacionales más amplias que integran coordinaciones y temas afines |
| V | **Coordinación** | Grupos internos que atienden necesidades del proyecto con tareas específicas; pueden tener Comités |
| — | **Comité** | Grupos de organización interna; pueden tener Mesas |
| VI | **Mesa** | Grupo pequeño con una sola tarea específica (ej. voceros, enlaces operativos), perfil especializado |
| VII | **Comisión** | Órganos que agrupan personas por temas y estados. Centro del Proyecto Migala. Crean productos y proyectos |
| VIII | **Titularidad** | Cargo o rol al que se delegó una responsabilidad mediante figura reglamentaria |
| IX | **Espacio amigable** | Lugar físico o digital con características para que asistentes se sientan en confianza, seguros y plenos |
| X | **Diálogo** | Conversación priorizando conocer y comprender el punto de vista del otro antes de opinar o decidir |
| XI | **Consenso** | *(definición truncada en fuente)* |

## Jerarquía organizacional (según glosario)

```
Proyecto Migala
  └── Áreas (IV)
       └── Coordinaciones (V)
            └── Comités (V)
                 └── Mesas (VI)
  └── Comisiones (VII) [por tema/estado]
  └── Miembros (III)
       ├── Afiliados
       └── Simpatizantes
```

**Observación:** El glosario revela una arquitectura de **profundidad variable**: las Áreas tienen hasta 4 niveles jerárquicos (Área → Coordinación → Comité → Mesa), mientras que las Comisiones son estructuras más planas.

## Función del glosario

- **Interpretación auténtica:** Las definiciones aquí contenidas son vinculantes
- **Seguridad jurídica:** Todos los miembros entienden los términos de la misma manera
- **Economía normativa:** Evita repetir definiciones en cada artículo

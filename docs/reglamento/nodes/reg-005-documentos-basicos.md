# Documentos Básicos del Proyecto Migala

## Idea atómica

Tres documentos fundamentales determinan la **línea ideológica, los fines y las acciones** del Proyecto Migala. Son la base normativa e ideológica sobre la que se asienta toda la organización.

## Los 3 Documentos (Art. 10)

### 1. El Manifiesto  `#ideologia #principios`
Declaración pública de **principios, ideología e intenciones oficiales** del Proyecto Migala.

**Función:** Define el "qué somos" y "en qué creemos".
**Custodio:** CONFU (Comité de Manifiesto, Art. 46).

### 2. El Reglamento  `#normativa #organizacion`
Normativa general de aplicación para todos los miembros. Define:
- Reglas de conducta
- Estructura orgánica del Proyecto

**Función:** Define el "cómo nos organizamos" y "cómo nos comportamos".
**Custodio:** Área Legal (Grupo de Estatutos y Reglamentos, Art. 91).

### 3. La Ruta Crítica  `#planeacion #accion`
Serie de **tareas o acciones** para materializar lo dicho en el Manifiesto y el Reglamento.

**Función:** Define el "qué hacemos" y "cuándo lo hacemos".
**Custodio:** Coordinación General (Art. 23) + Comité de Gestión de Proyectos.

## Relación entre documentos

```
Manifiesto (IDEOLOGÍA)
     │
     ▼
Reglamento (ESTRUCTURA)
     │
     ▼
Ruta Crítica (ACCIÓN)
     │
     ▼
Proyectos y Actividades
```

## Ciclo de vida documental

```
Creación/Modificación
  → CONFU (Manifiesto) / Área Legal (Reglamento) / Coord. Gral. (Ruta Crítica)
    → Revisión de coherencia (¿alineado al Manifiesto?)
      → Aprobación (Coord. General)
        → Publicación (YouTube + Notion)
          → Ejecución (Ruta Crítica)
```

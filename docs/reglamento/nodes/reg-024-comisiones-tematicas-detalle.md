# Comisiones Temáticas — Detalle y Obligaciones

## Idea atómica

Las 6 Comisiones Temáticas desarrollan posturas y proyectos en áreas del conocimiento humano relevantes para el Manifiesto. Tienen las mismas obligaciones que las comisiones estatales, con requisitos de conformación específicos.

## Lista completa (Art. 108)

| Comisión | Ámbito de acción |
|----------|------------------|
| **Arte y Cultura** | Expresión artística, patrimonio, gestión cultural, club de lecturas |
| **Ciencia y Tecnología** | Investigación, innovación, desarrollo tecnológico |
| **Estudios Económicos** | Economía política, desarrollo, finanzas |
| **Geopolítica e Historia** | Relaciones internacionales, análisis geopolítico |
| **Sustentabilidad** | Medio ambiente, cambio climático |
| **Derechos Humanos** | Derechos fundamentales, justicia social |

## Requisitos de conformación (Art. 109)

| # | Requisito |
|:-:|-----------|
| I | 2 representantes (paridad de género) |
| II | Reglamento interno de trabajo |
| III | Plan de acción o ruta crítica |
| IV | Diagnóstico interno |
| V | Notion o página de transparencia |

## Obligaciones (Art. 110)

Las comisiones temáticas tienen las **mismas obligaciones y responsabilidades** que las comisiones estatales, con excepción de los requisitos (son menos).

> Esto implica que deben: mantener comunicación abierta, generar espacios amigables, formar personas, buscar horizontalidad, sujetarse a transparencia, etc.

## Relación con afiliados (Art. 6, VIII)

Todo afiliado debe formar parte de **al menos una** Comisión Temática.

# Paridad de Género — Regla Estructural

## Idea atómica

La paridad de género es un **principio estructural transversal** en el Proyecto Migala. Todos los órganos deben regirse por la igualdad sustantiva entre mujeres y hombres, con una regla clara de 50/50 y medidas correctivas si no se cumple.

## Fundamento normativo

- **Art. 2 (Principios):** "El Proyecto Migala siempre buscará propiciar la paridad de género"
- **Art. 12:** "Dentro del Proyecto Migala todos los órganos de estructura deberán regirse por el principio de paridad de género, consistente en la igualdad sustantiva entre mujeres y hombres."
- **Art. 13:** Regla específica de aplicación
- **Art. 107, II:** Requisito para comisiones estatales

## La regla del Art. 13

### Escenario ideal
```
50% Mujeres  ←→  50% Hombres
```

### Tolerancia máxima (6 meses)
```
60%  ←→  40%
(Si no se cumple 50/50, se tolera hasta 60/40 máximo)
```

### Medidas correctivas

**En la tolerancia (60/40):**
El órgano carente debe **acordar dos proyectos** para corregir y acelerar el cumplimiento de la paridad, en coordinación con el grupo de identidad de género con menor proporción.

**Plazo:** Las medidas no pueden durar más de **6 meses**.

**Si no se cumple en 6 meses:**
El **Área Político Electoral** impone medidas de acción afirmativa para compensar la desigualdad.

### Exención

Los **Grupos de Perspectiva de Género** ([[reg-009]], [[reg-025]]) quedan exentos de este principio.

## Aplicación en la estructura

| Órgano | Aplicación de paridad |
|--------|-----------------------|
| Coordinación General (Art. 25-26) | 16 miembros: 1M + 1H + 1AA por cada grupo de 3 |
| Voceros (Art. 34) | Dupla por entidad: 1 mujer + 1 hombre |
| Comisiones Estatales (Art. 107) | 2 representantes con paridad |
| Comisiones Temáticas (Art. 109) | 2 representantes con paridad |
| Grupos Transversales (Art. 113) | ❌ Exentos |
| Demás órganos (Art. 12) | Todos deben regirse por paridad |

## Indicador cuantitativo

```
Índice de Paridad = (Mujeres en titularidades) / (Total de titularidades)
Meta: 0.50 (50%)
Tolerancia: [0.40, 0.60]
```
